# Workflow operation index

Generated by `bun scripts/feature-catalogue.ts --write`; checked by `bun run check`.

Canonical files stay grouped by format and operation, not source runtime. Rule and
scenario profiles distinguish policies within a family. Historical runtime names in
IDs are provenance, not portability verdicts. Feature tags below aggregate scenario
reviews; a mixed file is never labelled fully generalized.

See [classification criteria and all scenario rows](../docs/feature-reuse.md),
[feature CSV](../docs/feature-reuse.csv), [scenario CSV](../docs/scenario-reuse.csv)
and [contribution guidance](../CATALOGUE.md). The CSV also includes every staged
candidate file; those candidates are not canonical or presumed portable.

## Mutation fixture selection

`contracts/mutation-safety.json` selects eight IDs from five format-local files
(nineteen compiled cases). Loading a file does not activate its other scenarios.
Implementation status remains in `ledgers/workflows.json`; reuse tags grant no
execution credit.
